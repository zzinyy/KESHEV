## 적용·실행

작업 복사본은 Documents/Codex/2026-10-19/q/work/on-client이다. on-client에서 Node.js로 `node src/server.mjs` 실행. 다른 서버가 5189를 사용 중이면 PowerShell에서 `$env:ON_PORT='5195'` 지정 후 실행한다. 브라우저를 시작 로그 주소로 연다. 종료는 실행 창에서 Ctrl+C다.

원본 Workbench 프로젝트 학생 폴더의 쓰기 권한이 부여되지 않아 자동 적용하지 않았다. 원본 extension.mjs를 별도 안전한 위치에 백업하고 이번 extension.mjs 한 파일만 on-client/student/extension.mjs에 복사하면 된다. 기존 기록·.git·설정 파일·제공 런타임을 지우거나 덮어쓰지 않는다.

소스 ZIP은 개발 소스 보관본이지 공식 app.zip 또는 설치 패키지가 아니다. 공식 package-app 도구·승인 host·appearance.json 계약과 PC 상태 API는 현재 시작 틀에서 확인하지 못했다. CPU·메모리·디스크·방화벽·Windows 이벤트 실시간 조회를 추가했다고 주장하지 않는다. 공식 포장·운영 최종 제출은 아직 미완료다.

최신 0.2.14 제공 ZIP에도 start/demo/check만 있고 package-app이 없었다. 공식 업데이트 미리보기는 학생 설명을 추가한 README.md 때문에 UPDATE_FILE_MODIFIED로 중단했고 실제 파일은 변경하지 않았다. 기존 학생 내용을 보존한 상태로 다음 공식 업데이트 안내를 따라야 한다.
