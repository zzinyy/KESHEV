# 1~7일차 최종 재검증

2026-10-29, Windows·Node 24.21.0·Git 2.55.0.windows.5. 기존 22단계 Git 이력과 기존 파일을 유지했다. 포장은 실행하지 않았다.

## 구현 범위

| 일차 | 완료한 작업 | 증거와 제한 |
|---|---|---|
| 1 | 같은 누적 프로젝트 재실행, 핵심 3기능 선정 | CPU/메모리/디스크, 연결·방화벽, Windows 기록 집계 |
| 2 | PC 실측과 두 수동 조회의 CPU 추이 비교 | Node os·statfs 실제 반환, 시각·단위. 작업 관리자와 측정 구간은 다를 수 있음 |
| 3 | 일반 권한의 Windows 읽기 조회 | 네트워크·방화벽·System/Application이 이번 환경에서 읽기 제한으로 확인 불가. 설정 변경·관리자 실행 없음 |
| 4 | 네 상태 카드·반응형·수동 조회·대기·오류 표시 | 실제 브라우저와 키보드 Enter로 확인, 과거 추이는 현재 카드와 분리 |
| 5 | 실행/중지/재시작 안내, 오류 해결과 한계 문서 | 에이전트 재현. 다른 사람이 독립적으로 실행한 검증은 하지 않음 |
| 6 | 저장소와 커밋 정리, 원격 이력 보존 | 원격 main의 README 초기 커밋을 병합해 이력을 보존. 강제 push 없음 |
| 7 | 2분 시연 순서, 제공/학생 기능 경계, 미완료 사항 정리 | FINAL_SEVEN_DAYS.md 참조. 제출·실측 성공·실제 SDP 연결을 구분 |

## 재검증한 항목

- 학생 모듈 3개 문법 검사 통과.
- 현재 상태 대시보드 모의 입력 검사 통과. 과거 목록에 남은 수치를 현재 카드로 오인하지 않도록 검증 범위를 현재 카드로 한정했다.
- /daily와 기존 /의 HTTP 200, 외부 Origin 403, 학생 API POST·쿼리 405 확인.
- 로컬 PC API의 CPU·메모리·디스크 실측 응답 확인. 원시 측정 JSON·네트워크 이름·개인 값은 저장소나 포털에 업로드하지 않음.
- 브라우저에서 수동 조회 대기 및 결과 표시 확인. 초기 화면은 자동 수집하지 않음.

## 제출 범위와 남는 한계

마지막 총공세의 1~7일차는 권장 제작 순서이며 새 점수나 진도 기록이 아니다. 실제 외부 SDP·AI 연결·보안 집행은 이번 작업에서 검증하거나 승인하지 않았다. Windows 읽기 제한은 확인 불가로 남긴다. 다른 사람·다른 PC의 재현은 미확인이다. 관리자 권한 또는 보안 설정 변경으로 우회하지 않는다.

보안 도우미 키트나 수료용 도구는 이번 작업에서 설치하지 않았다. 수집 자료를 외부 AI에 전송하거나 매일 자동 점검을 등록하지 않았다. 최종 마무리 제출은 저장소 URL과 공개 GitHub의 정확한 커밋 번호만 사용한다.
